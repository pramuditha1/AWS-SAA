Outposts, Local Zones, Wavelength, and VMware Cloud

Know the nameDomains 3–4 · hybrid and edge placement

Most SAA workloads live in Regions. These products exist when the stem refuses a normal Region: data must stay in your building, users need metro latency, mobiles need 5G single-digit milliseconds, or the estate is VMware you will not convert.

Start here — the W questions

Why

Physics and law: some machines cannot wait for a Region round trip, and some data cannot leave a factory. Teams still want familiar AWS APIs or an unchanged vSphere world.

What

Outposts — AWS-managed racks in your datacenter. Local Zones — AWS-operated metro extensions of a Region. Wavelength — compute inside a telecom 5G network. VMware Cloud on AWS — managed SDDC on bare metal.

Where

Outposts sit on your floor. Local Zones sit in AWS metro buildings. Wavelength sits in a carrier POP. VMware Cloud runs in an AWS Region on dedicated hosts. Parent Region still handles much control-plane and snapshot gravity.

Which pieces matter

Residency → Outposts · city latency → Local Zones · 5G ultra-low latency → Wavelength · keep vSphere → VMware Cloud. Direct Connect is a cable, not a place to run compute.

Core knowledge (beginner foundations)

Pick from the constraint, not from the marketing word “edge.” CloudFront caches HTTP at POPs — it does not run your factory PLC loop. Global Accelerator improves paths into Regions — it does not place servers in a 5G radio network.

Case study 1 — factory residency

Stem

PLC data must stay in the plant with sub-10 ms to machines. Engineers want IAM, AMIs, and EBS-style volumes they know.

A — wrong Direct Connect to Regional EC2 — compute still leaves the building.
B — correct AWS Outposts in the factory.
C — wrong Wavelength — that is carrier 5G, not a private plant.
D — wrong Snowball Edge as a permanent cluster — Snow is primarily a transfer appliance you ship back.

Case study 2 — 5G game

Stem

Mobile game needs single-digit millisecond to 5G users; servers must sit in the carrier metro network, not 30 ms away in a Region.

A — wrong CloudFront — caches HTTP; does not host your game loop next to the radio.
B — correct AWS Wavelength zones with the carrier.
C — wrong Outposts in HQ.
D — wrong Global Accelerator alone.

Tricky points

Local Zones ≠ Outposts ≠ Wavelength. Who owns the building (you / AWS / carrier) is the tell.

Snapshots and control plane often still involve the parent Region — the exam still wants Outposts when the running workload cannot leave the site.
