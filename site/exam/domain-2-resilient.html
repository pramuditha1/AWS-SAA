Domain 2 — Design Resilient Architectures (26%)

Second highestTasks 2.1–2.2

Task 2.1 Scalable and loosely coupled

  • Multi-tier, microservices, stateless vs stateful
  • SQS, SNS, EventBridge, Step Functions, API Gateway
  • ALB, Auto Scaling, Lambda, Fargate, ECS, EKS
  • Caching, read replicas, edge (CloudFront)
  • Object vs file vs block storage

Task 2.2 Highly available and fault-tolerant

  • Multi-AZ vs Multi-Region, Route 53 failover
  • DR: backup/restore, pilot light, warm standby, active-active; RPO/RTO
  • RDS Proxy, immutable infrastructure, quotas/throttling
  • S3 durability, backups, X-Ray for visibility
